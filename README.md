Projeto Python: Controle de Versão com Git & GitHub
Este projeto foi desenvolvido como um exercício prático para aprender os fundamentos de controle de versão, gerenciamento de branches, resolução de conflitos de histórico e fluxo de Pull Requests.

🛠️ Tecnologias Utilizadas
Python: Linguagem de programação principal.

Git: Ferramenta de controle de versão local.

GitHub: Plataforma para hospedagem e colaboração de código.

VS Code: Editor de código.

🚀 Funcionalidades Implementadas
Atualmente, o script (script.py) realiza as seguintes operações:

Exibe uma mensagem de boas-vindas ao usuário.

Realiza um cálculo simples de soma (2 + 2).

🤝 Como Contribuir
Faça um Fork do projeto.

Crie uma nova Branch (git checkout -b feature/sua-feature).

Faça o Commit de suas alterações (git commit -m 'Adicionando nova feature').

Faça o Push para a Branch (git push origin feature/sua-feature).

Abra um Pull Request.
